## PHASE 5: TECHNICAL SEO ENHANCEMENTS (Week 17-20)

### 5.1 Schema Markup Implementation

**Already Implemented:**
- ✅ Breadcrumb schema
- ✅ OpenGraph tags
- ✅ Twitter cards

**Add These:**

1. **FAQPage Schema** - For every FAQ section
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "How do I enter cheat codes in GTA San Andreas?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Open the pause menu..."
      }
    }
  ]
}
```

2. **HowTo Schema** - For installation guides
```json
{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "How to Install GTA San Andreas on iOS",
  "step": [
    {
      "@type": "HowToStep",
      "name": "Open App Store",
      "text": "Launch the Apple App Store on your iPhone..."
    }
  ]
}
```

3. **VideoObject Schema** - For embedded videos
```json
{
  "@context": "https://schema.org",
  "@type": "VideoObject",
  "name": "GTA San Andreas Mission 1 Walkthrough",
  "description": "Complete walkthrough...",
  "thumbnailUrl": "...",
  "uploadDate": "2025-01-01"
}
```

4. **Article Schema** - For guide articles
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "GTA San Andreas Cheat Codes",
  "author": {"@type": "Organization", "name": "GTA San Andreas Info"},
  "datePublished": "2025-01-01"
}
```
