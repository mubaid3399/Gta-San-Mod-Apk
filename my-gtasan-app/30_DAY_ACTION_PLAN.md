### Day 17-18: Setup Schema Markup on All Pages

**For EVERY content page, add:**

1. **FAQPage Schema** (if page has FAQ)
   ```json
   {
     "@context": "https://schema.org",
     "@type": "FAQPage",
     "mainEntity": [...]
   }
   ```

2. **HowTo Schema** (if guide/walkthrough)
   ```json
   {
     "@context": "https://schema.org",
     "@type": "HowTo",
     "name": "...",
     "step": [...]
   }
   ```

3. **Article Schema** (all content)
   ```json
   {
     "@context": "https://schema.org",
     "@type": "Article",
     "headline": "...",
     "datePublished": "2025-01-XX",
     "dateModified": "2025-01-XX",
     "author": {...}
   }
   ```

**Tool:** Use structured data testing tool to validate
- [ ] Validate on all 3 new pages
- [ ] Fix any errors
- [ ] Add to existing pages (start with top 5)

**Time: 4-5 hours**
