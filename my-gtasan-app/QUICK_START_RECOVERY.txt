================================================================================
  WHAT WENT WRONG (Technical Explanation)
================================================================================

CVE-2025-55182: React Server Components Deserialization Vulnerability
- Attacker sends malformed RSC payload to /sitemap.xml
- Old Next.js 16.0.1 tries to deserialize unsafely
- Server crashes or returns 500 error
- Google's crawler hits error → marks site unstable
- Crawling stops → Indexing halts → 98% impressions drop

CVSE-2025-66478: Next.js Downstream Impact
- Same vulnerability, affects Next.js 15.x and 16.x with App Router
- Fixed in 16.0.7 (validates payloads safely)

RESULT: Old payload → 500 error (bad)
        New patch → 400 reject (good, crawling continues)
