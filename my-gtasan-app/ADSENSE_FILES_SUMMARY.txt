================================================================================
QUICK IMPLEMENTATION STEPS
================================================================================

BEFORE CODING:
  1. Go to https://www.google.com/adsense/
  2. Sign up with Google Account
  3. Submit your website for review
  4. Wait 3-7 days for approval

AFTER APPROVAL:
  1. Get your AdSense Client ID
     Format: ca-pub-XXXXXXXXXXXXXXXX

  2. Update 2 files with your Client ID:
     - app/layout.js (Line 113)
     - app/components/AdSenseAd.jsx (Line 19)

  3. Create ad units in AdSense dashboard:
     - Get Slot ID for each ad unit
     - Create 3-5 different ad units

  4. Add to your pages (examples provided):
     - Homepage: 1-2 ads
     - Article pages: 2-3 ads
     - Download page: 2-3 ads
     - Other pages: 1-2 ads

  5. Test locally:
     npm run dev

  6. Build and deploy:
     npm run build

COMPONENT USAGE
================================================================================

Basic Usage:
  import AdSenseAd from '@/app/components/AdSenseAd';

  <AdSenseAd adSlot="1234567890" format="auto" />

Props:
  - adSlot (string): Your ad unit slot ID (required)
  - format (string): 'auto', 'horizontal', 'vertical' (default: 'auto')
  - responsive (boolean): Enable responsive design (default: true)
