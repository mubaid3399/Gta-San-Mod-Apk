## TROUBLESHOOTING

### Pages Not Indexing
**Solution**:
1. Verify page is in sitemap ✓
2. Check page is publicly accessible
3. Use GSC URL Inspection to request indexing
4. Wait 24-48 hours
5. Check GSC coverage report

### Rankings Not Improving
**Solution**:
1. Increase content quality (2000+ words)
2. Optimize for keyword (H1, first 100 words)
3. Build internal links to page
4. Add external backlinks
5. Improve Core Web Vitals

### Low Traffic Despite Rankings
**Solution**:
1. Improve meta description for higher CTR
2. Add numbers to title tags
3. Use power words (best, complete, ultimate)
4. Update older content
5. Target better keywords (lower competition)
