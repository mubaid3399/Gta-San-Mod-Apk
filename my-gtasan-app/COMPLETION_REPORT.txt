================================================================================
  QUICK START GUIDE
================================================================================

1. READ DOCUMENTATION:
   Start with ANIMATION_QUICK_START.md for a one-page overview

2. VIEW EXAMPLES:
   Open HeroExamples.jsx to see working implementations

3. ADD TO YOUR COMPONENTS:

   Scroll Reveal:
   <ScrollRevealWrapper animation="fade-in-up">
     <YourComponent />
   </ScrollRevealWrapper>

   Auto Animate:
   <AutoAnimateWrapper className="space-y-4">
     {items.map(item => <Item key={item.id} />)}
   </AutoAnimateWrapper>

   Framer Motion:
   <motion.div initial={{opacity: 0}} animate={{opacity: 1}}>
     Content
   </motion.div>

4. TEST YOUR CHANGES:
   npm run dev

5. BUILD FOR PRODUCTION:
   npm run build
   npm run start
