## PART 11: TROUBLESHOOTING

### Issue: Impressions Still Not Recovering After 7 Days

**Check List:**
1. Is sitemap returning 200? `curl -I https://gtasanandreas.info/sitemap.xml`
2. Is robots.txt accessible? `curl -I https://gtasanandreas.info/robots.txt`
3. Are there crawl errors in GSC? Go to **Coverage** report
4. Check server logs for 5xx errors
5. Verify no `<meta name="robots" content="noindex">`

**Solutions:**
- Clear Cloudflare cache if using it: Purge All
- Resubmit sitemap in GSC
- Request indexing manually for top pages
- Check server uptime (any downtime = Google stops crawling)

### Issue: Coverage Shows "Excluded" Pages

**Common Reasons:**
- Duplicate content (check canonical tags)
- Robots.txt blocking
- Noindex tag applied
- Too slow to load (>30 seconds)
- Redirect loops

**Solutions:**
- Check GSC Coverage report for exclusion reason
- Verify canonical URLs
- Remove any noindex tags
- Test page load time: `curl -w "@curl-format.txt" -o /dev/null -s https://your-url`

### Issue: CTR Not Improving Despite Higher Impressions

**Problem:** Higher impressions but low CTR = bad titles/descriptions

**Solution:**
```
Analyze underperforming pages in GSC:
1. Go to Performance > Search Results
2. Sort by "Impressions" (highest first)
3. For pages with <2% CTR:
   - Rewrite title (add keyword + benefit)

   - Test in Google's SERP preview tool

Example rewrite:
BEFORE: "Home"
AFTER: "GTA San Andreas MOD APK 2025 - Unlimited Money | Safe Download"
```
